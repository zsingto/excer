# สรุปเลคเชอร์

> 🇹🇭 ดัดแปลงเป็นภาษาไทยจาก [VoltAgent/awesome-agent-skills](https://github.com/VoltAgent/awesome-agent-skills/tree/main/skills/lecture-notes) · License: MIT

## ทำอะไรได้

จดเลคเชอร์ Cornell method

## ขั้นตอน (เพิ่มเติมในเครื่อง)

1. อ่านเนื้อหาทั้งหมดก่อน (ไฟล์ PDF/สไลด์ใช้สกิล pdf/pptx/docx ดึงข้อความ)
2. ทำโน้ต 3 ส่วนแบบ Cornell:
   - **คอลัมน์ขวา (Notes)**: ประเด็นหลักตามลำดับที่สอน เป็นข้อสั้นๆ พร้อมนิยาม สูตร ตัวอย่าง
   - **คอลัมน์ซ้าย (Cues)**: คำถามหรือคีย์เวิร์ดที่ตรงกับแต่ละช่วงของ Notes ใช้ปิดคอลัมน์ขวาแล้วทดสอบตัวเอง
   - **ส่วนล่าง (Summary)**: สรุป 3–5 ประโยคด้วยภาษาตัวเอง
3. ใช้เฉพาะข้อมูลจากต้นฉบับ ส่วนไหนไม่ชัดให้ระบุว่าต้องตรวจสอบ ห้ามเดา
4. แสดงผลเป็นตาราง Markdown 2 คอลัมน์ (Cues | Notes) แล้วตามด้วย Summary

## เหมาะกับใคร

นักศึกษาที่ต้องส่งรายงาน/เลคเชอร์/สอบ

ใช้ตอน:

- อาจารย์สั่งงานเสาร์อาทิตย์ต้องส่งจันทร์
- ฟังเลคเชอร์ไม่ทัน อยากได้สรุปใช้อ่านสอบ
- ต้อง present หน้าห้องแต่ไม่รู้จะเริ่มยังไง

## บอก Claude ยังไง

แค่พิมพ์เป็นภาษาไทยปกติ ไม่ต้องจำชื่อ skill เพราะ Claude จะหยิบใช้เองตาม trigger ที่กำหนดไว้

ตัวอย่าง:

```
"ช่วยสรุปเลคเชอร์ ให้หน่อย บริบทคือ [อธิบายสถานการณ์ของคุณ]"
```

```
"สรุปเลคเชอร์ สำหรับ [กลุ่มเป้าหมาย], อยากได้แบบ [น้ำเสียง/สไตล์]"
```

Claude จะถามข้อมูลที่ยังขาด (เช่น กลุ่มเป้าหมาย น้ำเสียง บริบทธุรกิจ) ก่อนเริ่มทำงาน
